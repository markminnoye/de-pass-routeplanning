Je kunt een route eerst uitproberen, en de plugin kan zelf een kortere rit per kind voorstellen.

- Je probeert een scenario eerst uit als schatting. Die cijfers en de kaart volgen nog niet de echte weg. De echte tijden vraag je daarna één keer op bij TomTom. TomTom is de routeplanner die per berekening aangerekend wordt.
- De plugin zoekt zelf een kortere rit per kind: een betere volgorde van de stops, of een andere verdeling van de kinderen over de bussen. Een bus of een opstapplaats kun je vastzetten. De rest mag wel veranderen.
- Een nieuwe opstapplaats voeg je pas toe nadat je gezien hebt wat die TomTom-berekening kost.
- De leerlinggegevens zitten niet in de plugin. Die blijven in een aparte map.
- Op de kaart staat het stopnummer in de stip. In de legende zet je elke bus apart aan of uit. De kaart verschijnt ook in het gesprek.
- De voorbeeldritten rekenen met aankomst om 08:30.

Download het plugin-bestand bij deze release. Je vervangt de plugin in Claude via Plugin → Add.
