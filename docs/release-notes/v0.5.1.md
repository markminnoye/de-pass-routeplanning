Claude zegt aan het begin welke versie van de plugin hij gebruikt.

- Je hoort het versienummer meteen, ook als er geen nieuwere versie is.
- Is er wel een nieuwere versie, dan krijg je daarna de download, zoals voorheen.
- De kaart in het gesprek is het bestand dat de plugin maakte. Claude typt die kaart niet opnieuw over, want dan vallen de straten weg.

Download het plugin-bestand bij deze release. Je vervangt de plugin in Claude via Plugin → Add.
