De plugin kan nu alle kinderen opnieuw over de bussen verdelen.

- Een volledige school, tot ongeveer 150 kinderen, wordt opnieuw verdeeld. Dat kan enkele minuten duren, tot ongeveer vijf minuten. Daarna zie je wie van bus is gewisseld en of de rit per kind korter is.
- Een bus of een opstapplaats kun je vastzetten. De rest mag wel veranderen.

Download het plugin-bestand bij deze release. Je vervangt de plugin in Claude via Plugin → Add.
