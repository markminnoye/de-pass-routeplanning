De kaart in een gepubliceerd gesprek toont nu de straten.

- Tot nu toe bleef die kaart grijs: de stratenplaatjes mochten niet van internet komen. Die plaatjes zitten nu in het bestand zelf, voor het gebied van de rit.
- Open je de kaart in een gewone browser, dan komen de straten buiten dat gebied nog van OpenStreetMap.

Download het plugin-bestand bij deze release. Je vervangt de plugin in Claude via Plugin → Add.
