De bussen rijden naar school en halen de verste kinderen eerst op. De langste rit wordt daardoor korter.

- Een rit eindigt op school. De bus vertrekt bij het eerste kind. De lege rit vanaf school telt niet meer mee.
- Standaard is dat de ochtend. Je kunt ook de andere richting kiezen: de bus vertrekt dan op school en zet de verste kinderen als laatste af.
- Een volgorde die je zelf hebt vastgelegd, blijft zoals je ze schreef.

Download het plugin-bestand bij deze release. Je vervangt de plugin in Claude via Plugin → Add.
