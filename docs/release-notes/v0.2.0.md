Dit is de eerste versie waarmee je de schoolbusroutes van de pass kunt vergelijken.

- Je legt een scenario vast, bijvoorbeeld een bus die kinderen uit één streek ophaalt, vaste opstapplaatsen, of een andere verdeling over de bussen.
- Per scenario zie je de langste rit, de gemiddelde rit per kind, de totale rijtijd, de kilometers, hoe vol de bussen zitten en hoe laat ze op school zijn.
- De ritten staan op een kaart. Haltes van De Lijn, TEC en de NMBS kun je daarop tonen.
- Voor TomTom een route uitrekent, zie je eerst wat die berekening kost. TomTom is de routeplanner die daarvoor aangerekend wordt.
- Dezelfde vraag op dezelfde datum geeft dezelfde cijfers.

Download het plugin-bestand bij deze release. Je vervangt de plugin in Claude via Plugin → Add.
